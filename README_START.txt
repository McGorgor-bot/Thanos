THANOS 2.64.41 — szybki start

1. Rozpakuj całe archiwum ZIP do zwykłego folderu.
2. Uruchom dwukrotnie klikając Thanos.bat.
3. Pozostaw otwarte czarne okno terminala. Przy pierwszym uruchomieniu skrypt sprawdzi Pythona i zainstaluje biblioteki z requirements.txt.
4. Aplikacja otworzy się w przeglądarce.

Wymagania: Windows, Python 3.11 lub nowszy, dostęp do internetu przy instalacji bibliotek. Obsługa DWG wymaga osobno zainstalowanego ODA File Converter. Audyt XREF jest dostępny w module Lista kablowa, przy wczytanych plikach DXF.
